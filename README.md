---

## 🌟 Key Features

### 1. Modern Light Theme UI
- Ultra-responsive, clean design system built with custom CSS tokens, smooth glassmorphism header, and Google Fonts (`Outfit` & `Plus Jakarta Sans`).
- Full-bleed background slideshow featuring high-resolution executive vehicle and safari photography.

### 2. Practical & Executive Vehicle Lineup
- **Luxury Sedans**: BMW 5 Series, Audi A6, Hyundai Verna.
- **SUVs & MPVs**: Toyota Innova Crysta (7-Seater), Toyota Innova Hycross (Strong Hybrid), Maruti Suzuki Ertiga.
- **Value Sedans & Hatchbacks**: Maruti Suzuki Dzire, Hyundai Aura, Maruti Suzuki Swift.
- Interactive category filter pills (*All Vehicles*, *Luxury*, *SUVs & MPVs*, *Executive Sedans*, *Self-Drive*).

### 3. Quick Booking Search & Instant Fare Estimator
- Top agency hero search bar for instant vehicle availability queries.
- Interactive fare calculator providing real-time trip cost breakdowns based on vehicle model, trip type (local, outstation, airport, safari), and duration.

### 4. Bandhavgarh Tiger Safari Explorer
- Comprehensive zone guide for **Tala (Gate 1)**, **Magadhi (Gate 2)**, **Khitauli (Gate 3)**, and **Buffer Zones**.
- Details sighting probabilities, best months, terrain, and permit turnaround times.

### 5. Seamless WhatsApp Booking Integration
- One-click modal popup capturing traveler details (Name, Pickup Location, Vehicle, Date) and automatically formatting direct WhatsApp inquiries to `+91 78696 26201`.
